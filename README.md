# Carvix 🚗

## About the Project

Carvix is a smart vehicle maintenance and monitoring platform that helps users manage their vehicles and track maintenance activities.

## Project Objectives

- Manage vehicle information.
- Track vehicle maintenance records.
- Monitor vehicle activities.
- Provide smart AI assistance.
- Improve the vehicle maintenance experience.

## Technologies

- Python 3.12
- Django
- PostgreSQL
- HTML5
- CSS3
- JavaScript (ES6+)
- Agentic AI
